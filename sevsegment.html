LED Circuit

This project demonstrates the design and simulation of a 7-segment LED display using digital logic techniques in Falstad.

Project Information

  • Simulation Tool: Falstad Circuit Simulator
  • Components: Logic gates, 3-bit binary inputs, LED segments (A–G)
  • Techniques Used: Multiplexers, Decoders, PoS & SoP Implementation
  • Category: Digital Logic Design

How It Works

Binary input combinations represent numbers from 0–7. Depending on the active logic technique, each segment lights up to display the correct numeric pattern on the virtual 7-segment display in Falstad. The project highlights modular design principles and verifies logic through simulation before physical implementation.
