Circuit Projects

Here are some of my circuit design and embedded systems projects!

7 Segment LED Circuit

This project demonstrates how binary inputs can drive a 7-segment LED display using digital logic principles, simulated in Falstad to show segment control and output verification.

Traffic Light Circuit

This circuit simulates a traffic light control system built in Falstad using multiplexers and logic inputs to manage light sequencing based on control signals.

Combinational Circuit

This project involves designing and simulating a 2-bit full adder and multiplexer-based circuit in Falstad to perform binary addition and control different output combinations using select lines, then implementing and testing it on a breadboard.

Arduino Stopwatch Project

A stopwatch that measures the time between two button presses using Timer0 and the millis() function on the ATmega328P.
